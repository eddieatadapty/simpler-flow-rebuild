# Simpler Growth Audit

**Live → https://eddieatadapty.github.io/simpler-flow-rebuild/**

Five ideas to turn more Simpler users into subscribers, each built into a clickable version of Simpler's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the answers you collect | +10–20% CR to purchase |
| 02 | Sell the course as a course, priced per month | +10–15% ARPU, from a bigger annual share |
| 03 | Let them solve one real exercise first | +5–15% CR to purchase |
| 04 | Show the proof before the price | +5–10% CR to purchase |
| 05 | Catch the people who close the paywall | +3–8% CR to purchase |

Every price, rating and feature comes from Simpler's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Simpler. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
